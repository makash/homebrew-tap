# makash/tap

Homebrew tap for [Agent Blast Radius](https://abr.kloudle.dev).

```sh
brew install makash/tap/blast
blast            # offline scan + share card
blast verify     # check which keys are live (paid per check, your own wallet)
```

Formulas install prebuilt, checksum-pinned binaries from
[makash/agent-blast-radius releases](https://github.com/makash/agent-blast-radius/releases).
Agent Blast Radius is proprietary software; see the license in that repository.
